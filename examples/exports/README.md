# Export examples

Run the app, load the sample workspace, approve one or more items, and use the
export buttons to generate current JSON, CSV, and SIE-style draft output.

The checked-in files in this folder are illustrative snapshots only. They are
not legally validated SIE files and must not be posted without human review.

CSV summaries include source columns when the imported item keeps filename or
row-number traceability.
